# niio 範例圖片

此目錄存放技能使用的圖片，位於自動產生的 `skills` 目錄之外，避免同步時覆蓋已處理版本。

- 圖片已逐張檢查；可辨識的品牌名稱與標誌以圖片編修工具移除，保留原有場景。圖片為示意素材。
- `localization/image-catalog.json` 記錄來源網址的雜湊、檔名、檔案內容雜湊及審查狀態，不保存原廠網址。
- Action 依對照表產生 `sample_images.json`，圖片網址指向本儲存庫的 Raw 檔案。
- 上游新增未審查圖片、檔案缺少或內容雜湊不同時，停止同步並保留既有技能。檢查與必要編修完成後，才更新對照表。
- 更新這些圖片或對照表會觸發重新產生技能；勿直接修改產生後的圖片清單。
