# niio 檢視外掛開發技能

## 簡介

這是一個專業的技能，用於建立和開發niio 自訂檢視外掛。提供完整的外掛開發工作流：專案初始化、依賴安裝、啟動除錯、欄位解析、API呼叫、建置釋出等全流程支援。

## 適用場景

- ✅ 資料看板、BI 駕駛艙
- ✅ 訂單/任務看板檢視
- ✅ 日曆、甘特圖檢視
- ✅ 地圖檢視
- ✅ 簡單清單、卡片展示
- ✅ 自訂業務檢視

## 核心能力

1. **完整的開發工作流**
   - 7步完整流程（從環境檢查到釋出上線）
   - 自動選擇合適模板（JavaScript/React/React-Tailwind/Vue）
   - 靜默執行，使用者無需手動操作

2. **欄位型別處理**
   - 正確處理單選欄位 (type 9)
   - 處理多條關聯欄位 (type 29)
   - 完整的欄位型別對照表

3. **API 整合**
   - mdye 內部 API（目前表操作）
   - niio V3 公開介面（跨表、高階功能）
   - 透視表統計 API

4. **BI 駕駛艙設計**
   - 業務分析師視角設計
   - 完整的指標定義規範
   - 資料視覺化最佳實踐

5. **開發除錯支援**
   - 完整的問題排查流程
   - 快速診斷指令碼
   - 常見錯誤解決方案

## 關鍵要點

### 使用者反饋規則（必須嚴格遵守）

**❌ 嚴禁輸出的內容：**
- 除錯地址
- "請複製到niio..."之類的指引
- 專案結構說明
- 命令執行日誌
- "啟動完成"、"編譯成功"等技術狀態

**✅ 正確的做法：**
- 啟動伺服器後，保持完全靜默
- 簡單回覆："已完成,請在niio中檢視效果。"
- 修改後回覆："已修改"
- 釋出後回覆："已釋出"

### 開發伺服器管理

- ✅ 使用 `run_in_background: true` 啟動開發伺服器
- ✅ 伺服器應該一直保持執行狀態
- ❌ 永遠不要主動關閉開發伺服器
- ❌ 只有使用者明確要求時才關閉

### 建置和釋出流程

- ✅ 每次修改程式碼後，立即執行 `mdye build && mdye push`
- ✅ 主動完成釋出，不需要使用者額外操作
- ❌ 不要等使用者提醒才釋出

### 模板選擇建議

- 📊 **資料看板、BI 駕駛艙** → `React` 或 `React-Tailwind`
- 📅 **日曆、甘特圖** → `React`
- 🗺️ **地圖檢視** → `React`
- 📝 **簡單清單、卡片展示** → `JavaScript` 或 `React-Tailwind`

### 欄位型別重要提示

- ⚠️ **Type 9** = 單選 (SingleSelect) - 注意不是 type 11
- ⚠️ **多條關聯欄位** (type 29) 回傳數字，需要呼叫 `getRowRelationRows` API
- ⚠️ **單條關聯欄位** (type 29) 回傳 JSON 字串，可以直接解析
