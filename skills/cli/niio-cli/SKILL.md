# niio CLI 使用導航

niio CLI（命令 `hap`）把 niio 企業平台的後端能力封裝成命令列，覆蓋：
通訊錄與部門、聊天訊息與群組、動態、日程、工作表記錄讀寫、檢視與欄位、
工作流與審批待辦、自訂頁面、角色權限、組織與應用管理、檔案上傳與分享。

## 第一步：確認 niio CLI 已安裝

```bash
hap --version
```

**有版本號輸出就跳到下一步。** 報 `command not found` 就先裝：

```bash
pip install hap-cli
```

裝完再跑一次 `hap --version` 確認。如果 pip 裝成功但 `hap` 仍然找不到，說明它被裝進了
不在 PATH 上的 Python 環境，改用 `python3 -m pip install --user hap-cli`，或用
`python3 -m hap_cli` 代替 `hap` 呼叫。

## 登入前先確認環境

先讀本機命令說明，尚未確認目標時不要啟動登入：

```bash
hap guide
hap guide setup
hap auth login --help
```

依本機版本提供的唯讀帳號與設定查詢，確認部署網址（含路徑）、profile、組織及應用。`hap auth whoami` 只能作為身份證據之一，不能單憑登入成功判定目標正確。

既有相符帳號可沿用。缺少設定時依該版本說明設定已確認的部署，再登入；不假設預設登入指向 niio，不複製 MCP 憑證、不自動切換全域組織或預設應用。優先使用該版本支援的單次 profile／應用選擇。命令或部署不支援時保留待辦並說明原因。


## 第二步：每次動手前先跑 `hap guide`

```bash
hap guide
```

它會給出**目前這臺機器上這一版 niio CLI** 的完整命令地圖、可用的細分主題，以及最常踩的坑。
命令地圖是現場生成的，永遠和實際能跑的命令一致。

需要具體某方面的細節，按 `hap guide` 輸出裡列出的主題深入，例如寫記錄的取值格式、
登入與環境管理、從訊息觸達記錄、什麼時候該轉交其他 skill。

## 鐵律

**不要憑記憶拼命令名或參數。**

CLI 版本可能不同，命令和參數也可能改變；是否自動更新依安裝方式而定。任何時候都以這兩個為準：

- `hap guide` —— 能做什麼、該走哪條路
- `hap <命令> --help` —— 這個命令的確切參數

寫資料尤其要小心：不同欄位型別的取值格式差別很大，而且**傳錯基本不會報錯**，
伺服器端照樣回傳成功但資料是壞的。動手前先看 `hap guide` 裡的記錄寫入主題，
寫完讀回確認。
